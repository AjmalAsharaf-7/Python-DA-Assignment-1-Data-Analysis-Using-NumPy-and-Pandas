# Python DA Assignment 1: Data Analysis Using NumPy and Pandas

## 📌 Project Overview

This project focuses on learning the fundamentals of data analysis using Python libraries such as **NumPy** and **Pandas**. The assignment covers array operations, Series manipulation, and DataFrame analysis.

## 🎯 Objectives

* Understand NumPy arrays and their properties.
* Perform basic numerical operations using NumPy.
* Convert temperatures from Celsius to Fahrenheit.
* Practice array indexing and slicing.
* Create and manipulate Pandas Series.
* Create and explore Pandas DataFrames.
* Filter, group, and analyze data using Pandas.
* Perform basic data manipulation operations.

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Jupyter Notebook / Google Colab

## 📂 Assignment Tasks

### 1. NumPy Array Operations

* Create a one-dimensional NumPy array containing Week 1 temperature data.
* Inspect array shape, data type, and number of elements.
* Convert Celsius temperatures to Fahrenheit.
* Calculate maximum, minimum, and mean temperatures.
* Perform array indexing and slicing.
* Create a two-dimensional array containing temperature data for two weeks.
* Extract weekly temperatures and weekend temperatures.

### 2. Pandas Series

* Create a Pandas Series containing student marks with custom indices.
* Access values using integer indexing, `loc`, and `iloc`.
* Filter marks greater than 90 using Boolean masking.
* Update the first-ranked student's mark.
* Remove the last-ranked student's entry.
* Calculate CGPA by dividing marks by 10.

### 3. Pandas DataFrame

* Create a DataFrame containing transaction details.
* Explore the dataset using `head()`, `tail()`, `shape`, `columns`, and `dtypes`.
* Select specific columns.
* Retrieve the last three columns.
* Filter transactions based on region and amount.
* Calculate product category value counts.
* Identify unique regions.
* Calculate the average transaction amount for each region.

### 4. DataFrame Manipulation

* Update the amount for TransactionID 102 to 165.
* Add a Discount column calculated as 10% of the transaction amount.
* Remove the row with TransactionID 109.
* Delete the Discount column.
